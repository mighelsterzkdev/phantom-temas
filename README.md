# phantom-temas

Imagens e sons dos temas de evento do Phantom Menu, um tema por pasta:

- `halloween/`: tema Halloween.
- `natal/`: tema Natal.
- `icones/`: fonte com os ícones do menu.

## Origem

- `halloween/bat-*.png`: quadros do GIF de morcego feito para o Phantom Menu.
- `halloween/vignette.png`: gerada por código.
- `natal/snowflake-*.png`: quadros do GIF de floco feito para o Phantom Menu.
- `natal/bells-open-fade.wav`: trecho adaptado de "Sleigh Bells Sound", de Alexander / Orange Free Sounds
  (https://orangefreesounds.com/sleigh-bells-sound/), licença CC BY 4.0
  (https://creativecommons.org/licenses/by/4.0/). Cortado em 2,5 segundos, com filtro passa-alta e fade out a partir de 0,65s.
- `natal/sleigh-right.png` e `natal/sleigh-left.png`: "Santa's Sleigh And Reindeer Silhouette", de GDJ
  (https://openclipart.org/detail/291102/santas-sleigh-and-reindeer-silhouette), domínio público pelo Openclipart,
  adaptada pelo autor de uma imagem do Pixabay. Reduzida à metade, pintada de branco (a cor vem do menu) e espelhada na
  versão da esquerda.
- `icones/tabler-icons.otf`: ícones server, shield, calendar, users e building-community do Tabler Icons 3.44.0
  (https://tabler.io/icons), licença MIT, Copyright (c) 2020-2026 Paweł Kuna. Ficam nas letras a (server), b (shield),
  c (calendar), d (users) e e (building-community).
- As demais imagens foram feitas para o Phantom Menu.
